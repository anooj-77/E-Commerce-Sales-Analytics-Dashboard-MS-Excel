# E-Commerce Sales Analytics Dashboard | Excel

An interactive Excel dashboard designed to explore e-commerce sales performance, track key business metrics, and turn raw order data into clear, actionable insights.

## Project Overview

This project presents an e-commerce sales analysis in Microsoft Excel. It brings together a visual dashboard, supporting calculation tables, and the underlying dataset in one organized workbook.

The dashboard uses a professional navy-and-teal colour theme, KPI cards, charts, structured analysis tables, and interactive filters to make the results easy to explore.

## Workbook Structure

| Worksheet | Purpose |
|---|---|
| **Dashboard** | Main visual dashboard with key performance indicators, charts, and interactive filters. |
| **Calc** | Supporting calculations, summary tables, monthly and yearly analysis, and helper data used by the dashboard. |
| **Data** | Raw e-commerce order-level dataset used for the analysis. |

## Dashboard Highlights

- **Sales performance:** Review total revenue and order activity.
- **Key performance indicators:** View metrics such as total revenue, total orders, and average order value.
- **Time-based analysis:** Explore monthly and yearly sales performance.
- **Category analysis:** Compare sales across product categories.
- **Regional analysis:** Understand how sales are distributed across regions.
- **Order-status analysis:** Review the order statuses available in the dataset.
- **Customer analysis:** Explore customer-level performance, including top customers.
- **Interactive filtering:** Use the available dashboard filters to focus on selected periods and business segments.

## Calculations and Analysis

The `Calc` worksheet contains supporting analysis, including:

- Monthly revenue and order summaries
- Yearly revenue and order summaries
- Average order value
- Delivered and returned/cancelled order summaries
- Average discount analysis
- Category, region, order-status, and customer summaries

The calculation sheet remains visible so the analysis can be reviewed.

## Design Approach

The dashboard uses a professional corporate colour palette:

- Deep navy for visual hierarchy and section headers
- Blue and teal accents for charts and highlights
- White KPI cards for readability
- Light grey backgrounds for a clean layout
- Consistent table formatting for easier comparison

## Tools Used

- Microsoft Excel
- Excel formulas and built-in charting
- Data cleaning, aggregation, and analytical reporting

## How to Use

1. Open the workbook in Microsoft Excel.
2. Go to the **Dashboard** worksheet.
3. Use the available filters to explore the data.
4. Review the charts and KPI cards for performance insights.
5. Open the **Calc** worksheet to inspect supporting summaries and calculations.
6. Refer to the **Data** worksheet to view the source records.

> For the best experience, open the workbook in the desktop version of Microsoft Excel.

## Project Purpose

This project demonstrates practical skills in spreadsheet-based data analysis, KPI development, dashboard design, data summarization, and business reporting. It showcases how raw e-commerce data can be organized into an interactive and easy-to-understand analytical dashboard.
